🚀 Project Overview
This project involves a comprehensive end-to-end data analysis of the Brazilian Olist E-commerce dataset. The primary objective was to extract actionable business insights by evaluating key performance indicators (KPIs), analyzing customer purchasing behavior, and identifying logistical bottlenecks within the supply chain.

🛠 Tech Stack
Data Ingestion & Cleaning: Python (Pandas)

Database Management: MySQL, SQLAlchemy

Data Modeling: Star Schema (Power BI)

Data Visualization: Microsoft Power BI

Analytical Engine: DAX (Data Analysis Expressions)

📊 Key Insights & Business Impact
Revenue Strategy: Identified the state of 'SP' as the highest revenue-generating hub, providing a clear focus for regional marketing campaigns.

Logistics Optimization: Analyzed delivery lead times to pinpoint performance gaps, enabling data-driven suggestions for improving customer satisfaction scores.

Customer Loyalty: Engineered custom DAX measures to calculate repeat purchase frequency, serving as a baseline for future Customer Lifetime Value (CLV) initiatives.

📈 Project Workflow
Data Pipeline: Developed Python-based ETL scripts to transform high-volume raw CSV data into a structured MySQL relational database.

Data Modeling: Designed a Star Schema to enable efficient cross-filtering between transactional (Orders) and dimensional (Customer/Product) data.

Dashboarding: Built an interactive Power BI dashboard featuring sales trends, payment method analysis, and product quality metrics to support executive decision-making.
